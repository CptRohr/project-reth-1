Because i and some of my friends wants to make one ourselves after we decided to do it before graduation.
- **Why using Godot specifically?**
First of all it's FOSS and free and i have past experience working with it, i used to thinking about using Unity or even Unreal but Nah im good with Godot.
- **When the game will be finished?**
It's a long project, its like doing long marathon. It will be ready when it's ready. We're working on it when we feel like it so no pressure or anything.

I'm pretty sure it will available to play on Mobile and Windows through itch.io and later it will be available on Google Play Store for the Mobile version, well no promise :D
