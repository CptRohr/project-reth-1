# Game that developed by us RETHorizon Studio

This is side scrolling horror game about high school students, except not boring school stuff only. It supposed to be social sim, life sim, and probably emotional damage simulator all at once. You manage daily life, make choices, suffer consequences, and maybe survive long enough to see another day. Very normal teenage behavior, yes.

We making this project with chaos, passion, and enough caffeine to keep whole studio standing. If you want contribute, contact me or reach out through SNS. Support, feedback, ideas, and weirdly specific bug reports all welcome. Thank You :D

### QnA
- **Why making this game?**
Because me and some friends wanted make one ourselves after we decided to do it before graduation. We thought, why not spend free time building nightmare with school uniforms.

- **Why using Godot specifically?**
First of all, it's FOSS and free. Also have past experience with it, and Godot feels like home. I thought about Unity or even Unreal, but nah, im good with Godot. Less drama, more game.

- **What kind of game is this?**
Side scrolling horror with social sim and life sim layers. Think choices, routines, relationships, and occasional panic when something goes wrong. So, basically, school life but louder.

- **When the game will be finished?**
It's long project, like running marathon while carrying keyboard. It will be ready when it's ready. We working on it when we feel like it, so no pressure, no countdown, no ritual sacrifice.

- **Where can i play the game when it's done?**
Pretty sure it will be available on Mobile and Windows through itch.io. Later, Mobile version may show up on Google Play Store too. No promise, because destiny love surprises :D

- **Can i help?**
Yes. If you want contribute, send message, share idea, help with art, code, design, QA, or just tell us what part looks cursed. Every bit help.

- **Is project serious?**
Very serious. Extremely serious. Serious enough to contain jokes in README and probably several bugs in code.
